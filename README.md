# 🚗 Sistema de Gestión de Parqueadero - Ejercicio Java

¡Bienvenido al repositorio **Ejercicio_java**! Este es un proyecto desarrollado en **Java** con interfaz gráfica **Java Swing** y patrón de arquitectura **MVC (Modelo-Vista-Controlador)** para la gestión y control del ingreso y salida de vehículos en un parqueadero.

---

## 📋 Características Principales

- 🚘 **Registro de Vehículos:** Registro eficiente de ingreso y salida de automóviles y motocicletas.
- ⏱️ **Cálculo de Tarifas:** Control del tiempo de estancia y cobro automático según el tipo de vehículo y tarifa configurada.
- 🎨 **Interfaz Gráfica (GUI):** Interfaz amigable desarrollada con **Java Swing** para facilitar la interacción del usuario.
- 🏗️ **Arquitectura MVC:** Separación limpia de la lógica de negocio, datos y presentación (Modelo, Vista y Controlador).
- 📊 **Control de Ocupación:** Monitoreo y consulta del estado de disponibilidad de los espacios/celdas del parqueadero.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java (JDK 8 o superior)
- **Librería Gráfica:** Java Swing / AWT
- **Arquitectura:** MVC (Model-View-Controller)
- **IDE Sugeridos:** NetBeans, IntelliJ IDEA, Eclipse o VS Code
